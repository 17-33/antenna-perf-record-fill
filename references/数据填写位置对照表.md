## 4. GT-公式法（行 4–11）

**列定义**

| 列 | 含义 | 来源 |
|---|---|---|
| `D` | 实测增益 | 引用方向图 `T5:T12`（**不用更新**） |
| `E` | 馈线波导 | **接收低频段**取值 |
| `F4` | 标准偏差 σ | 面型最佳拟合（合并 `F4:F11`） |
| `G` | 面精度 Lm | `Lm = 685.81 × σ² / λ²` |
| `H` | 天线罩 Lc | IQC《天线罩插入损耗》 |
| `I` | Tant = **230**（常量） | T0 = 290 K |
| `J` | LNB 噪声系数 | LNB 供应商数据（大纲允许引用供应商数据） |
| `K` | Tr | `Tr = 290(10^(NF/10)−1)` |
| `L` | G | — |
| `M` | G/T | `G/T = (G−L) − 10lg(TA+Tr)` |

门限：**G/T ≥ 25 dB/K（含天线罩）**。

**面精度损耗公式**：`Lm = 685.81 × σ² / λ²`（σ、λ 同单位；`λ(mm) = 300 / f(GHz)`）

## 5. 跟踪精度

| 格 | 含义 | 填法 |
|---|---|---|
| `B4:B13` | 天线方位角-姿态(°) | 截图编号 n → 行号 **n+3** |
| `C4:C13` | 天线俯仰角-姿态(°) | 同上 |
| `A14` | 零值 | 公式，不手填 |
| `A15` | 单轴 | 公式，不手填 |
| `B16` | 合成 | 公式，不手填 |
| `C17` | 指标 | `=(方向图!J5+K5+N5+O5)/2/10`（公式，不手填） |

判定：**跟踪精度 ≤ 1/10 × 3dB 波束宽度**，`δ = √(δA² + δE²)`，δA/δE = 读数对零值的 RMS。
来源列 = `D`。

> ⚠️ 口径：必须取 BAT Pro「**ANT 状态**」面板的**姿态**角（不是传感器 / 编码器角）。同页"传感器"角波动大（实测 10 次波动 0.83°），**换字段会从合格变不合格**，务必让用户书面确认。

## 10. 指标汇总（技术大纲）

| 项 | 要求 | 公式 / 常量 |
|---|---|---|
| EIRP | **≥ 69 dBW**（含天线罩） | `EIRP = P + G − L`，`L = Lf + Lfeed + Lc` |
| G/T | **≥ 25 dB/K**（含天线罩） | `G/T = (G−L) − 10lg(TA+Tr)`，`Tr = 290(10^(NF/10)−1)`，TA = 230 K |
| 跟踪精度 | **≤ 1/10 × 3dB 波束宽度** | `δ = √(δA²+δE²)`，δA/δE = 读数对零值的 RMS |
| 工作频段 | RX 37.5–40.05 / TX 47.2–49.8 GHz | RX 每频段 3 点共 8 点，TX 同（含重合频点） |
| 方向图增益 | 无独立门限（供 EIRP / G-T 用） | `G ≈ 31000/(AZ3·EL3)`、`G ≈ 91000/(AZ10·EL10)` |
| 第一旁瓣 | 大纲未给限值（仅要求记录） | — |
